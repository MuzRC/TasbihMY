TASBIHMY - PANDUAN PEMASANGAN CEPAT (PWA OFFLINE-READY)
============================================================

Kandungan Fail:
1. index.html    - Kod antaramuka utama & enjin zikir
2. manifest.json - Konfigurasi PWA (tajuk, tema gelap & ikon)
3. sw.js         - Service Worker untuk keupayaan offline 100%
4. icon-192.png  - Ikon aplikasi saiz standard (Android / Home Screen)
5. icon-512.png  - Ikon aplikasi resolusi tinggi (Splash Screen)
6. icon.svg      - Fail rekaan ikon vektor asli

------------------------------------------------------------
CARA GUNA / PASANG:
------------------------------------------------------------
PILIHAN A: Guna Terus di Komputer / Laptop
- Cuma perlu 'double-click' fail 'index.html' untuk buka di browser Google Chrome, Edge, atau Safari.

PILIHAN B: Pasang Jadi App Rasmi di Telefon Pintar (Android / iPhone)
1. Muat naik semua fail ini ke GitHub Repository (contoh: 'tasbihmy').
2. Buka Settings repo -> Bahagian 'Pages' -> Pilih 'Deploy from branch main'.
3. Buka pautan web GitHub Pages anda di telefon menggunakan Google Chrome (Android) atau Safari (iOS).
4. Tekan butang menu 3 titik di Chrome dan pilih "Install app" / "Add to Home screen".
   (Untuk Safari: Tekan butang 'Share' -> 'Add to Home Screen').
5. Siap! Ikon TasbihMY akan muncul di skrin utama dan boleh dibuka tanpa sambungan internet.
